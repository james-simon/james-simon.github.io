Event data

Paste JSON — either {"meta":…, "shows":[…]} or a bare array. Each entry needs a name, a start (and end or durationMin), and coordinates in venue.lat / venue.lng. Optional: genre, blurb, note, status, venue.room, venue.address, venue.confidence, and sessions for shows with several slots. Saved to this browser only.
