{% comment %} Moving between the homepage and any other page animates its dark background into that page's nav bar, or the nav bar back into the homepage. Browsers without cross-document view transitions (and anyone who prefers reduced motion) just change pages. A page only ever plays one of the two animations (the homepage plays "arriving home", the rest "arriving from home"), so those styles apply from the first frame, without waiting for a script. Navigations between two pages of the same kind still run a transition, but an instant one: the old page stays on screen until the new one is ready, which avoids a blank flash. The animation for arriving home is in index.html, and the one for arriving anywhere else is below. {% endcomment %}
